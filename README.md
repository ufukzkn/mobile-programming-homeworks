## HW1 quick start

Use Flutter **3.47.6 Stable**.

```sh
git clone https://github.com/ufukzkn/mobile-programming-homeworks.git
cd mobile-programming-homeworks/hw1
flutter pub get
flutter devices
flutter run
```

For platform setup, tests, screenshots and credits, see [HW1 README](hw1/README.md).
